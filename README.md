# CrazAI

CrazAI is a Python sentiment analysis project with a Streamlit app and batch CLI located in [sentiment-analysis/](sentiment-analysis/).

## Production Entry Points

- [sentiment-analysis/app.py](sentiment-analysis/app.py) for the Streamlit application
- [sentiment-analysis/main.py](sentiment-analysis/main.py) for batch model runs
- [LICENSE](LICENSE) for the repository license

## Run Locally

```bash
cd sentiment-analysis
pip install -r requirements.txt
streamlit run app.py
```
